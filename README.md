## Build with Lovable

Projektet är byggd med hjälp av [Lovable](https://lovable.dev). 

Länk till projektet: [Lovable editor](https://lovable.dev/projects/d6c2d0a9-bbb4-422c-a970-09d751d0224f).

**Synkronisering med GitHub**

Projektet är kopplat till GitHub genom Lovable:

- **Stay in sync**:  Ändringar som görs i Lovable committas direkt till detta repository.
- **Full ownership**: Koden ägs av projektet och kan ändras direkt via GitHub. Ändringar som pushas till `main` synkas tillbaka till Lovable.

## Development

**Förutsättningar**
För att köra projektet lokalt behöver du:
- Node.js
- npm 

[install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
